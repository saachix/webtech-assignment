# Campus Collab – Student Creator Collaboration Hub

Campus Collab is a web application that helps students discover and create collaboration opportunities based on their skills and interests.

## Live Website

https://webtech-assignment-production.up.railway.app/

## GitHub Repository

https://github.com/saachix/webtech-assignment

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- HTML
- CSS
- JavaScript
- MySQL / MariaDB
- Apache Tomcat
- Maven
- Railway

## Features

- Student registration and login
- Student profiles with bio, skills and portfolio links
- Create collaboration opportunities
- Browse and search collaborations
- Filter collaborations by category
- Sort collaborations by latest and most voted
- Apply to collaborations
- Accept or reject applications
- Voting system
- Dark mode

## Deployment

The application is deployed using Railway with Apache Tomcat and a Railway MySQL database.
